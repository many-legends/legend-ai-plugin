# Legend for ChatGPT and Codex

This package connects to the Legend MCP server through OAuth. It reads the connected account, positions, orders, and fills. It can prepare an exact perpetual limit-order proposal for review in Legend. It cannot execute orders, transfer funds, or withdraw funds. Production access is limited to approved accounts.

The public source and local ZIP are preparation artifacts. No OpenAI directory approval or publication is claimed. The review test cases in the manifest are specifications; a fresh hosted run, a dedicated reviewer account, and a video walkthrough are still required. Never put credentials in this package.

Upload the ZIP through https://platform.openai.com/plugins and use the With MCP flow. The server is https://app.legend.trade/api/connectors/mcp. Complete OAuth and domain verification in the portal. Read the findings before submitting for review.
